# interview-preparation/

Everything for interviews, in one place. The **Interview prep** button in the
board header opens this folder.

Keep it here rather than inside individual job folders. Most preparation is
reusable across applications, and material scattered across twenty folders is
material you will not find when you need it.

Suggested contents:

```
README.md                    an index: which file to open when
INTERVIEW-PREP.md            behavioural questions, your story, the plan
STORY-BANK.md                the stories themselves, in detail
QA-<topic>.md                technical Q&A per subject area
<COMPANY>-prep.md            company-specific notes
```

**This directory is gitignored apart from this README**, because your notes will
contain company names, salary expectations and candid assessments of your own
gaps. None of that belongs in a public repository.

One suggestion from experience: write your technical answers around problems you
have actually solved rather than definitions. An answer that is a formal
statement of a bug you personally fixed survives follow-up questions; a
memorised definition does not.
